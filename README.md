## About Me

I am a graduate researcher in the School of Computer Science and Technology at Southwest University of Science and Technology (SWUST), supervised by Prof. Huang Xiaofang. My work focuses on building lightweight, interpretable machine learning systems that operate reliably under real-world network encryption and embedded hardware constraints.

* **Research Focus:** Encrypted mobile traffic classification (TLS 1.3 / QUIC), paired-view gradient boosted decision trees (LightGBM / AOSO-LogitBoost), unseen-application generalization, and category-based policy filtering on consumer routers.
* **Systems & Embedded Engineering:** Custom OpenWrt and Armbian firmware builds, kernel modules, `nftables` packet filtering, and native C / Go edge inference on Redmi AX6, Raspberry Pi 4B, and Orange Pi 4 LTS (RK3399).
* **Computer Vision & Deep Learning:** Real-time object detection and multi-backbone ensemble benchmarking (River Plastic detection on Tesla T4 GPUs using PyTorch and Ultralytics YOLO).
